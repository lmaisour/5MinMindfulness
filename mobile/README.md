# 5MinMindfulness (mobile)

Expo React Native client for personalized 5-minute mindfulness meditations.

## Run

```bash
npm install
npx expo start
```

## Phase 1 notes

- Design tokens: `src/theme/tokens.ts`
- App name: `src/constants/brand.ts`
